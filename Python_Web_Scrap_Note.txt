→FIX POWERHELL EXECUTION POLICY (Safe Method)
i. Open PowerShell as Administrator
ii. Then run: Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
iii. It will ask: Do you want to change the execution policy?
iv. Type: Y and press Enter
v. Now activate again: Close PowerShell.
vi. Open new PowerShell (normal, not admin).
vii. Then run: msc_env\Scripts\activate
viii. Now it should show: (msc_env) PS C:\Users\navee> (That means virtual environment is active)

→If You Don't Want to Change Policy (Alternative Way)
You can activate using: msc_env\Scripts\activate.bat

8.Test Case: Create new file: api_test.py

import requests
import json

url = "https://osgtool.com/wp-json/wp/v2/product/52503002"

headers = {
    "User-Agent": "Mozilla/5.0"
}

response = requests.get(url, headers=headers)

data = response.json()

print("Product Title:", data.get("title", {}).get("rendered"))
print("Product ID:", data.get("id"))
print("Product Content:", data.get("content", {}).get("rendered"))
